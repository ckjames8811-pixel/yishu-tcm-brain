# 六经与八纲学习模块

本模块用于学习《伤寒论》等经典中的六经与八纲概念、条文语境和不同注家解释。

> 仅用于经典学习与知识整理；不用于个人诊断、处方或用药决定。

## 学习范围

- 六经：太阳、阳明、少阳、太阴、少阴、厥阴
- 八纲：阴阳、表里、寒热、虚实
- 条文阅读：原文、版本、篇章位置与注释
- 概念辨析：不同解释之间的相同点与差异

## 学习方法

1. 阅读原文并标注版本来源。
2. 记录关键词在上下文中的含义。
3. 对照至少一种注家解释。
4. 将不确定或有分歧的内容标记为“待核验”。
5. 不将古典学习框架直接套用于现实个人症状。

## 后续资料卡格式

每张资料卡应包括：

- 主题
- 原典出处
- 版本信息
- 概念说明
- 注家差异
- 审核状态
