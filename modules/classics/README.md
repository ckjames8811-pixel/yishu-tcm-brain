# 经典学习模块

本模块用于组织公开中医经典的学习索引、条文出处、版本差异和阅读笔记。

> 本模块服务于文献学习与知识整理，不构成医疗建议或个体化诊疗依据。

## 规划范围

- 《伤寒论》：六经相关条文与版本注释
- 《金匮要略》：杂病篇章与概念索引
- 《黄帝内经》：基础理论、藏象与经络相关篇章
- 《神农本草经》：传统本草文献资料卡

## 收录规范

每一篇学习资料至少包含：

- 原典名称与篇章
- 采用版本与出版或公开来源
- 原文节选范围
- 术语注释
- 不同注家或版本的差异说明
- 审核状态与最后更新时间

## 不收录内容

- 未确认授权的现代讲义、课程转写或付费资料
- 可识别个人身份的医案资料
- 未经来源核验的疗效、剂量或治疗结论
