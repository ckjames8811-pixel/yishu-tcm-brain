# 易枢中医大脑

> 面向中医经典学习、条文检索与知识整理的 AI Skill。

易枢中医大脑帮助学习者建立“经典原文 → 出处追溯 → 概念辨析 → 学习笔记”的学习路径。

## 使用边界

- 本项目仅供学习与研究，不构成医疗建议。
- 不提供诊断、处方、个体化用药剂量或急救操作指令。
- 如有紧急或严重症状，请立即联系当地急救服务或执业医生。
- 所有资料应保留来源、版本、版权状态与审核记录。

## 计划模块

- 六经与八纲：经典学习框架
- 伤寒与金匮：条文、方证与版本注释
- 黄帝内经：基础理论索引
- 本草：传统文献资料卡
- 针灸：经络与穴位理论
- 知识治理：来源、审核和更新记录
