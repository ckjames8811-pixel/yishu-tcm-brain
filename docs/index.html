002 / 学习方式

三步建立知识脉络

读原典、查出处、做辨析。

01

阅读原典

从明确篇章与版本出发，不脱离上下文摘取结论。

02

追溯出处

保留版本、页码、注家与资料状态，便于复核。

03

概念辨析

比较不同解释路径，并将未确认内容标为待审核。

003 / 使用原则

严谨，是易枢的第一能力。

把“依据来自哪里、适用边界是什么”设计进每一次知识整理。

01出处优先　记录版本、来源与审核状态。
02学习优先　不把理论资料包装成医疗结论。
03风险优先　紧急或严重情况应寻求当地急救与执业医生帮助。
